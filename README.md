# Vincent Anthony Abellana — Portfolio

Client-focused automation portfolio built with React, Vite, and Tailwind CSS.

## Open in Visual Studio Code

1. Extract this ZIP anywhere on your computer.
2. Open the extracted `vincent-portfolio` folder in Visual Studio Code.
3. Open the built-in terminal (`Ctrl` + `` ` ``).
4. Run `npm install` once to install the project packages.
5. Run `npm run dev`.
6. Open the local address shown in the terminal (normally `http://localhost:5173`).

## Create a production build

Run `npm run build`. The ready-to-deploy files will be created in the `dist` folder.

## Main files to edit

- `src/App.jsx` — all portfolio text, case studies, sections, and contact links
- `src/index.css` — colors, animations, and visual styling
- `public/projects/` — case-study images
- `public/Profile.png` — profile image
